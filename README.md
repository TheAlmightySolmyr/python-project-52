# Task Manager

[![Python](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![Django](https://img.shields.io/badge/Django-4.2-green.svg)](https://www.djangoproject.com/)

---

Task Manager — это веб-приложение для управления задачами, построенное на основе классического MVC-паттерна. Приложение позволяет создавать и отслеживать задачи, назначать исполнителей, управлять метками и статусами задач.

## 🚀 Возможности

- **Управление пользователями**: регистрация, аутентификация, управление профилями
- **Управление статусами**: создание, редактирование и удаление статусов задач
- **Управление задачами**: полный CRUD для задач с возможностью фильтрации
- **Управление метками**: система тегирования задач
- **Аутентификация**: защита доступа к функциям управления

## Установка

### Предварительные требования

- Python 3.8+
- PostgreSQL
- UV (для управления зависимостями)
